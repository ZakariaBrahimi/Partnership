# Brand assets

`flexdz-logo.svg` and `mizaniyapay-logo.svg` are **placeholders**. The official logos could not be fetched automatically.

To go live, overwrite both files with the official SVGs (keep the file names). They are rendered at a fixed height with
`width: auto`, so any aspect ratio works. A transparent background is recommended.

Brand colors live in `tailwind.config.ts` (`flex.*` and `mz.*` / `sun.*`). The MizaniyaPay navy/yellow come from the
existing coin mark; the FlexDZ orange is an assumption — update it to the official value.
