# Brand assets

`mizaniyapay-logo.png` is the official MizaniyaPay logo (navy `#1E4E67`, yellow `#F8E71B`).
`flexdz-logo.svg` is still a **placeholder**; overwrite it with the official FlexDZ logo (keep the file name).

Logos render at a fixed height with `width: auto`. Brand colors live in `tailwind.config.ts` (`flex.*`, `mz.*`, `sun.*`).
